# Audio Assets Required

This directory should contain the following audio files for the interactive narrative experience:

## Required Audio Files

1. **fire-crackling.mp3**
   - Description: Looped sound of fire crackling
   - Used for: Path 1 (Red Lanterns - Left path)
   - Playback: Loops continuously while hovering
   - Suggested length: 3-10 seconds (will loop)

2. **footsteps.mp3**
   - Description: Looped sound of walking footsteps
   - Used for: Path 2 (Footprints - Center path)
   - Playback: Loops continuously while hovering
   - Suggested length: 2-5 seconds (will loop)

3. **screaming.mp3**
   - Description: Looped screaming or eerie sound
   - Used for: Path 3 (Spider Webs - Right path)
   - Playback: Loops continuously while hovering
   - Suggested length: 3-10 seconds (will loop)

## Audio Requirements

- **Format**: MP3 (most compatible)
- **Quality**: Medium quality (128-192 kbps recommended)
- **Volume**: Normalized to consistent levels
- **Looping**: All sounds should be designed to loop seamlessly

## How to Add Audio Files

1. Place the audio files in this `assets/` directory
2. Ensure the filenames match exactly as listed above
3. The application will automatically load and play them

## Free Audio Resources

You can find free audio files from:
- [Freesound.org](https://freesound.org)
- [Zapsplat.com](https://zapsplat.com)
- [Pixabay Audio](https://pixabay.com/sound-effects/)
- [OpenGameArt.org](https://opengameart.org)

## Note

The application will work without audio files, but the hover sound effects will be missing. The visual interactions will still function correctly.
